ble center
设备可作为蓝牙主机， 连接蓝牙键盘和蓝牙鼠标。
设备也可以作为蓝牙hid从机，被电脑连接
设备也可以通过usb插入电脑，模拟hid鼠标键盘

然后功能是， 接收蓝牙键盘和鼠标的消息，通过蓝牙发送给多台电脑也可以通过usb发送给电脑。

鼠标的移动分为两种方式
1. 跨电脑进行鼠标移动，鼠标的移动只能发生在一台电脑上。移动到边界后会切换到另一台电脑上。鼠标移动到哪台电脑上 键盘的输入就在哪台电脑上。
2. 不跨电脑使用，也就是同时给多台电脑同时发送鼠标移动和键盘事件。
如果是跨电脑使用，就需要在内部虚拟出多台电脑的尺寸，实时根据鼠标移动距离计算最新的鼠标绝对位置，给电脑发送的鼠标坐标是绝对位置。
如果是不跨电脑使用，也需要在内部虚拟出一台电脑的尺寸，实时根据鼠标移动距离计算最新的鼠标绝对位置，给电脑发送的鼠标坐标是绝对位置。

配套的webhid_test.html 可以进行如下操作
1. 设备作为蓝牙主机，主动扫描蓝牙设备，并连接蓝牙键盘和蓝牙鼠标
2. 设备作为蓝牙hid从机，可以设置被发现，被连接，也可以操作断开和某台电脑的连接
3. 设置虚拟电脑的分辨率等信息，分辨率直接决定了跨电脑使用的虚拟

初步设计，
作为蓝牙主机 最多可以连接一个蓝牙键盘一个蓝牙鼠标。 
作为蓝牙hid，最多可以被2台电脑同时连接。
usb模拟的hid始终开启，也就是鼠键可以通过usb的hid发送给电脑
所以可以是一台蓝牙电脑加上一个usb的hid， 也可以是两个蓝牙电脑， 这个可以通过webhid_test.html 进行设置
